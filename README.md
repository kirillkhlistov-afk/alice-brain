# Alice Brain — свой «мозг» для Яндекс Станции Лайт (YNDX-00025)

Полностью свой голосовой помощник поверх rooted-колонки: офлайн-распознавание
русской речи, свой голос, встроенные навыки и LLM-мозг по API.

## Что умеет из коробки

- Wake-слово (по умолчанию «алиса», настраивается в конфиге)
- Офлайн-распознавание речи (Vosk, работает без интернета)
- Встроенные навыки: «который час», «какое сегодня число», «погода» (wttr.in),
  таймеры («поставь таймер на пять минут», «отмени таймеры»), шутки, приветствия
- Бесплатная музыка: интернет-радио (SomaFM, Радио Record) голосом или с панели:
  «включи музыку», «включи чилловую музыку», «выключи музыку»
- Управление лампочкой: Yeelight по локальной сети или любая лампа из Home
  Assistant: «включи свет», «выключи свет», «поставь красную подсветку»,
  «яркость 50 на лампе»
- LLM-мозг: любые вопросы через OpenAI-совместимый API (ключ в конфиге)
- Русский голос: espeak-ng офлайн (быстро) или Silero TTS (красиво, опционально)

## Установка на колонку

Предполагается, что на Станции Лайт уже получен root и есть SSH/ADB-доступ.
Актуальная инструкция по root для YNDX-00025 — в проекте
[yandex-station-extended](https://github.com/Marker284/yandex-station-extended)
и на hackalice.me (откат прошивки → root ADB).

### Авто-установка по Wi-Fi (рекомендую)

Ничего руками вводить на колонке не надо — всё делает программа с ПК.
На компьютере (в той же Wi-Fi-сети, что колонка) нужен Python 3 и adb:

```bash
python tools/alice_install.py
```

Windows: скачай папку `tools/` и запусти двойным кликом `install_windows.bat`.

Программа сама:
- сканирует Wi-Fi-сеть и находит колонку (ADB-порт 5555 или SSH);
- если adb нет на ПК — скачивает Android platform-tools;
- копирует проект на колонку;
- если на колонке нет Python — скачивает standalone-сборку для aarch64;
- ставит vosk, ffmpeg, создаёт конфиг;
- запускает ассистента и проверяет панель.

В конце она напечатает адрес панели для телефона/ПК.

### Root-помощник (если колонка ещё стоковая)

Если на колонке нет root, установщик сам напечатает пошаговую инструкцию
DNS-метода для Лайт (по wiki [hackalice.me](https://hackalice.me/start/root/)):
сброс колонки, привязка в «Доме с Алисой», DNS `179.254.167.126` на роутере.
Останутся только физические действия (кнопка на колонке, приложение, роутер) —
дальше установщик сам дождётся root и продолжит установку без тебя.
Это делается один раз.

### Установка вручную (альтернатива)

Скопируй папку проекта на колонку и запусти:

```bash
sudo ./install.sh
```

Скрипт поставит зависимости, скачает модель распознавания, положит конфиг в
`/etc/alice-brain/config.json` и включит автозапуск сервиса `alice-brain`.

## Настройка

`/etc/alice-brain/config.json`:

```json
{
  "name": "Алиса",
  "city": "Москва",
  "llm": {
    "api_base": "https://api.openai.com/v1",
    "api_key": "sk-...",
    "model": "gpt-4o-mini"
  },
  "server": {"host": "0.0.0.0", "port": 8080},
  "speech": {
    "wake_words": ["алиса", "слушай"],
    "tts_engine": "espeak"
  }
}
```

- `api_base` можно указать на любой OpenAI-совместимый сервер (OpenRouter,
  локальный llama.cpp, vLLM и т.д.)
- без `api_key` помощник работает офлайн: навыки отвечают, на свободные темы —
  честно говорит, что мозг не подключён
- `tts_engine: "silero"` — более естественный голос (нужно место под torch)
- лампа: `"light": {"type": "yeelight", "host": "192.168.1.100"}` или через Home
  Assistant: `{"type": "homeassistant", "ha_url": "http://...", "ha_token": "...",
  "entity_id": "light.my_lamp"}`
- музыка: `"music": {"engine": "mpv", "default_station": "record-rus"}` (на
  колонке нужен mpv, его ставит install.sh)

## Приложения для ПК и телефона

**Телефон** — отдельное приложение не нужно: веб-панель — это PWA. Открой
`http://IP-колонки:8080` в Chrome/Safari → меню браузера → «Добавить на главный
экран». Появится иконка и полноэкранное приложение.

**ПК** — приложение на tkinter в папке `apps/pc`, работает на Windows, Linux и
macOS без установки зависимостей (нужен только Python 3):

```bash
python3 apps/pc/alice_desktop.py http://IP-колонки:8080
```

Умеет всё то же: чат текстом, громкость, лампа (вкл/выкл/цвет), музыка
(стоп/выбор станции).

## Панель управления (можно с телефона)

Внутри есть веб-панель: чат с помощником текстом, статус,
счётчик таймеров и громкость. Она поднимается сама при командах `run` и `serve`.

```bash
python3 -m brain.main serve          # только панель, без микрофона
python3 -m brain.main run            # голос + панель вместе
```

Открой в браузере на устройстве в той же Wi-Fi-сети: `http://<IP-колонки>:8080`.
Настройки порта и адреса — в конфиге, секция `"server": {"host", "port"}`.

Произнести фразу одной командой:

```bash
python3 -m brain.main say "Привет, я новая Алиса"
```

## Отладка без колонки

Текстовый режим на любом компьютере:

```bash
python3 -m brain.main chat
```

Запуск голосового режима вручную (лог в консоль):

```bash
python3 -m brain.main run
journalctl -u alice-brain -f
```

Список аудиоустройств: `python3 -m brain.main devices`.

## Безопасность

- Любые модификации прошивки — риск окирпичить устройство, гарантия слетает
- Root держи только в своей домашней сети, обновления колонки лучше отключить,
  иначе root слетит — см. документацию сообщества
